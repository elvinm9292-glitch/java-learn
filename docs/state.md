## Сейчас в работе — Core Java: коллекции

По договорённости 2026-11-01 новые функции остановлены, проходим фундамент.
Пункты разбора (`docs/review.md`) ждут, к ним вернёмся после коллекций.

Пройдено:
1. **`ArrayList` против `LinkedList`** — понял: сейфовые ячейки подряд против
   цепочки; по умолчанию `ArrayList`, для очереди `ArrayDeque`.
2. **`HashMap`, `equals`/`hashCode`** — дался тяжело, но в конце сформулировал сам:
   «если не написать `hashCode`, каждому новому объекту свой случайный ящик,
   одинаковые не встречаются, `equals` даже не вызывается».
   Помогли: картотека по первой букве фамилии, смена фамилии (Алиева → Мамедова),
   запуск `learning/collections/HashCodeDemo.java`.
   Чего не делать: давать load factor, `return 1` и рецепты одним сообщением
   с основой — путает.

3. **`HashSet`, `TreeMap`, `ArrayDeque`, `PriorityQueue`** — пройдены 2026-11-02.
   Лучше всего зашло сравнение с SQL (таблица на одну/две колонки, B-tree
   индекс = `TreeMap`) и с Python (`dict` = `HashMap`, `set` = `HashSet`).
   Шпаргалка — `docs/collections.md`.
   Понял сам: `HashMap` для одного поиска не нужен — идти в базу; окупается,
   когда поисков много. Дубли ключа: `put` заменяет, для группы — `Map<K, List<V>>`.

не проведено — по правилу из `CLAUDE.md` оно должно быть перед следующей темой.
